# Oaykay Forgings - Industrial Inventory & Dispatch System

Enterprise web application for Oaykay Forgings Pvt Ltd to manage inventory master ledgers, division hierarchies (DIM, DIN, DTR), stock write-off audits, and sales order dispatch workflows (packing list and carton label generation).

## Technology Stack
- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Vanilla CSS & Tailwind CSS
- **State Management:** Zustand
- **Spreadsheet Processing:** SheetJS (xlsx)
- **Icons:** Lucide React

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
